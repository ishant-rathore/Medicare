## Design North Star

When a medicine is due, Medicare must make the reminder loud, visible, understandable and easy to acknowledge.

Key rules: large scalable typography, high contrast, oversized touch targets, simple wording, shallow navigation, voice-first but never voice-only interaction, visible status labels/icons and clear offline feedback.
