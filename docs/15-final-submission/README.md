## Submission Focus

The final submission should demonstrate the approved Medicare baseline: senior-first accessibility, voice-first but voice-optional interaction, reliable local reminder execution, Taken/Snooze/Skip actions, secure synchronization and explicit caregiver authorization.

## Evidence Rule

Do not present planned tests, fieldwork, participant information, usability scores or community-trial outcomes as completed results without actual evidence. Replace placeholders only with verified project records.

## Safety Boundary

Medicare is a medication reminder and organization tool. It does not diagnose, prescribe, change medication dosage/frequency or provide autonomous clinical advice.
